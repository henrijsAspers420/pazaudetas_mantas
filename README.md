# Pazaudētas mantas
Lietotne pazaudētu mantu meklēšanai.

## Lietotājiem

**Pievienot mantu**: nospiediet pogu "pievienot atradumu".

**Datu ievade**: katram ierakstam jāpievieno nosaukums, apraksts un fotoattēls.

**Meklēšana**: pazaudētas mantas var meklēt katalogā vai izmantojot meklēšanas funkciju.

**Navigācija**: lai atgrieztos sākumlapā, jānospiež uz lietotnes logo.

## Administratora panelis

**Piekļuve**: pārlūkprogrammas adreses joslā linka beigās jāpieraksta /unlock/OVG2026.

**Funkcijas**: admin panelis ļauj dzēst vai noņemt nevēlamus ierakstus no datubāzes.
